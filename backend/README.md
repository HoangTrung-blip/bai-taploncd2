# Medicine Reminder Backend

## Description
NestJS backend API for the Medicine Reminder application.

## Setup

```bash
cd backend
npm install
```

## Configuration
Copy `.env.example` to `.env` and update the values:
```bash
cp .env.example .env
```

## Running

```bash
# development
npm run start:dev

# production
npm run build
npm run start:prod
```

## API Documentation
Swagger UI is available at `http://localhost:3000/api/docs` when the server is running.
